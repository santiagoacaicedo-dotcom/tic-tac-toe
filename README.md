# Tic Tac Toe

Aplicación web del juego Tres en Raya (Tic Tac Toe), desarrollada en Java EE 
utilizando Servlets y JSP. Desplegada en un servidor Apache Tomcat sobre 
Ubuntu Server.

## Características

- Juego interactivo en el navegador
- Mensajes de interfaz en español
- Opción de iniciar el juego el usuario o el computador
- Detección automática de ganador (usuario, computador o empate)

## Tecnologías utilizadas

- Java EE (Servlets, JSP, JSTL)
- Apache Tomcat 9
- Eclipse IDE
- Ubuntu Server (VirtualBox)
